DESCRIPCION DEL PROYECTO 
Se ha trabajado con una base de datos de una tienda de películas ficticia. La base de datos consta de las siguientes tablas:
actor
addres
category
city
country
customer
film
film_actor
film_category
inventory
language
payment
rental
saff
store
La relación de las tablas las indico en la imagen: Diagrama ER
Se han realizado las consultas requeridas a través de estas herramientas:
● PostgreSQL.
● DBeaver.
Dichas consultas se indican en el fichero Script-1- Proyecto.

OBJETIVO DEL PROYECTO
He aprendido a manejar la herramienta DBeaver y he intentado plasmar la teoría aprendida en el módulo utilizando consultas simples o más complejas, utilizando relaciones entre tablas o subconsultas. 
También he creado una vista, que se muestra en el Diagrama ER y también una tabla temporal.
